# 10 — Roadmap

## Fase 0: documentação

- Criar estrutura inicial do repositório.
- Documentar visão, MVP, motor de partida, clubes, carreira, monetização e roadmap.
- Registrar decisões já tomadas.

## Fase 1: setup web

- Criar app Next.js.
- Configurar TypeScript.
- Configurar Tailwind CSS.
- Definir layout mobile-first.
- Configurar padrões de lint, formatação e testes.

## Fase 2: autenticação e personagem

- Integrar Supabase Auth.
- Criar perfil de usuário.
- Criar personagem jogador.
- Selecionar posição principal inicial.

## Fase 3: clubes e elenco

- Criar clubes.
- Definir presidente e técnico.
- Gerenciar elenco até 40 jogadores.
- Relacionar 23 jogadores por partida.

## Fase 4: motor de cenas

- Criar modelo de cenas.
- Criar decisões simultâneas.
- Implementar timer de 15 segundos.
- Aplicar bot por offline e sem resposta.
- Garantir cálculo autoritativo no servidor.

## Fase 5: partida 11vs11 MVP

- Criar lobby de partida.
- Criar fluxo de escalação.
- Rodar partida simplificada por cenas.
- Registrar placar, eventos e estatísticas básicas.

## Fase 6: ranking, estatísticas e moderação

- Criar rankings básicos.
- Criar histórico de partidas.
- Criar denúncias.
- Criar logs administrativos.
- Criar ferramentas iniciais anti-cheat.

## Fase 7: carreira, temporadas e legado

- Evoluir carreira.
- Criar temporadas.
- Criar envelhecimento.
- Criar aposentadoria.
- Criar legado histórico sem pay-to-win.

## Fase 8: APK Android

- Avaliar estabilidade da aplicação web.
- Preparar empacotamento com Capacitor.
- Testar experiência mobile.
- Publicar APK somente após validação do MVP web.
